# projetos/

Templates de **projetos integradores** — atividades de porte maior que uma
única aula, tipicamente reunindo conceitos de um bloco inteiro da
disciplina ou integrando outras disciplinas (caso do T2, interdisciplinar
com Desenvolvimento Web II e Engenharia de Software II).

Segue a mesma estrutura padrão de `templates/<alvo>/` (Fase 2 do processo
de geração deste repositório), mas fica em uma pasta separada para deixar
clara a diferença de escopo/peso em relação a uma atividade de aula única.

Nenhum projeto integrador foi processado como alvo até o momento. Ver
`docs/projetos-integradores.md` para o mapeamento de quais aulas já
processadas alimentam projetos futuros esperados (ex.: a Atividade T1,
prefigurada na Aula 01).
